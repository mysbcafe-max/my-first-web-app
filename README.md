## シフト生成ツール(一店舗用)

https://mysbcafe-max.github.io/my-first-web-app/shift-single/

一店舗のシフトを組むためのツールです。登録したスタッフ情報(フロア対応の可否・キッチン対応の可否・レベル・この期間の出勤日数・勤務できる曜日・対応できる時間帯・希望休)と、店舗設定(シフトを作る期間・定休日・時間帯ごとの必要人数)から、期間内の日付 × 時間帯のアサイン表を作ります。

- データはブラウザ内(localStorage)にだけ保存され、外部サービスには送信しません(費用ゼロ)
- 出勤日数は各スタッフに登録した日数を上限に、できるだけその日数に近づけます
- 時間帯ごとに「フロア必須〇人・キッチン必須〇人」「必要なリーダーレベル」「平日/土日で必要人数を変える」を設定できます
- 結果は CSV(日付別・スタッフ別)で書き出せ、印刷にも対応しています
- 「データ」タブのサンプルで動作を試せます

ファイル構成:

| ファイル | 役割 |
|---|---|
| `shift-single/index.html` | 画面 |
| `shift-single/style.css` | スタイル |
| `shift-single/app.js` | 画面の処理(保存・フォーム・結果表示) |
| `shift-single/scheduler.js` | 生成ロジック(UI に依存しない) |
| `shift-single/test/` | ロジックのテスト(`node --test "shift-single/test/*.test.js"`) |

### 生成ロジックの概要

1. 埋めにくい日(候補者に対して必要枠が多い日)から順に処理する
2. 各時間帯で、フロア必須・キッチン必須の人数を優先して、候補が少ない担当から埋める
3. リーダー要件がある枠は、そのレベル以上の人を先に 1 名入れる
4. 出勤日数の残りが多い人ほど優先し、いつもと同じ時間帯・連勤の少なさも考慮してスコアで選ぶ
5. 同じ日の時間帯どうしで担当を入れ替えて、埋められる不足があれば埋める
6. 人数不足・リーダー不在・出勤日数の未達は警告として表示する
